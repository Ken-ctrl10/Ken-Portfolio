# Ken Castillo — Portfolio

Personal portfolio of Prince Kenneth Castillo, a Computer Science graduate working
across React, Node.js, Express, and PostgreSQL. Originally built in plain
HTML/CSS/JS and later rewritten as a React single-page app.

**Live:** deployed on Vercel

## Stack

| | |
|---|---|
| Framework | React 19 |
| Build | Vite 8 |
| UI primitives | MUI 9 (Dialog, Drawer, Chip, IconButton) |
| Styling | Plain CSS with semantic custom properties |
| Images | WebP, generated by a `sharp` script |

## Getting started

```bash
npm install
npm run dev      # dev server with HMR
npm run build    # production build to dist/
npm run preview  # serve the production build locally
npm run lint     # ESLint
```

## Project layout

```
public/
  certificates/      46 certificate scans (WebP)
  projects/          project screenshots (WebP)
  og-image.jpg       1200x630 social preview card
scripts/
  optimize-images.mjs  image pipeline (see below)
src/
  components/        one folder per page section
  data/              page content, kept separate from markup
  hooks/             useInView (scroll reveal)
  assets/css/        one stylesheet per page + global.css
  theme.js           MUI theme, both colour schemes
_originals/          full-resolution source images (not deployed)
```

Page content lives in `src/data/` rather than in JSX, so copy, projects, and
contact links can be edited without touching components.

## Theming

Colour is defined once as semantic custom properties in
[`src/assets/css/global.css`](src/assets/css/global.css) — `--surface`,
`--text-muted`, `--border`, and so on. Dark mode overrides **only those values**
under `.dark-mode`; no component has a dark-mode-specific rule.

The `.dark-mode` / `.light-mode` class is written onto `<html>` by a small inline
script in `index.html` that runs *before* the app bundle, so a returning
dark-mode visitor never sees a flash of the light theme. First-time visitors get
their OS preference. [`src/theme.js`](src/theme.js) mirrors the same palette into
MUI so its components inherit it.

Adding a colour means adding a token, not another dark-mode selector.

## Images

Source images live in `_originals/`. The optimizer resizes each to roughly twice
its rendered CSS size, converts to WebP, and writes it into `public/` or
`src/assets/`:

```bash
npm run optimize:images
```

It is idempotent — originals are archived on first run and re-read on every run
after, so images are never re-compressed. It also regenerates `og-image.jpg`.

This pipeline took the production build from ~17 MB to ~1.6 MB.

## Accessibility

- All animation is gated behind `prefers-reduced-motion` — the certificate
  marquee, scroll reveals, and the hero typing effect all settle.
- Modal and mobile navigation use MUI `Dialog`/`Drawer` for focus trapping,
  Escape to close, and focus restoration.
- Every image carries explicit `width`/`height` to prevent layout shift.
- Sections are labelled with `aria-labelledby`.
